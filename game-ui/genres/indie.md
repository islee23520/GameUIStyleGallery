## Observed Screens

- Remember frames exploratory scenes with a torn-paper outline rather than a conventional HUD.
- Mushroom Oasis uses a compact bottom dialogue card against illustrated environments.
- The dating sim uses a bottom dialogue strip and small text controls beneath character art.
- These are narrative examples, not evidence of an "indie HUD". Indie is a publishing context that crosses genres; no common in-game layout is supported by this sample.
